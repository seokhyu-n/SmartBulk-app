# SmartBulk

AI 기반 개인 맞춤 운동 추천 및 자세 피드백 Android 애플리케이션

## 프로젝트 소개

SmartBulk는 사용자의 신체 정보(나이, 키, 몸무게)와 운동 목표를 기반으로 맞춤 운동 루틴을 추천하고, 카메라 기반 자세 분석을 통해 운동 피드백 제공을 목표로 개발한 헬스케어 앱입니다.

운동 중 사용자의 자세를 인식하여 운동 수행 상태를 분석하고, 피드백 문구를 제공하는 기능을 구현하였으며, 자세 인식 정확도 향상을 위한 임계값(threshold) 조정 및 모델 적용을 실험했습니다.

## 주요 기능

### 사용자 관리
- 회원가입 / 로그인
- 사용자 프로필 저장
- 운동 목표 설정

### 맞춤 운동 추천
- 사용자 정보 기반 운동 루틴 추천
- 운동 상세 화면 제공
- 세트(Set), 횟수(Reps) 안내

### 자세 피드백 (실험적 구현)
- 카메라 기반 운동 자세 인식
- MoveNet 모델 기반 포즈 추정
- 운동 수행 시 피드백 문구 제공
- 자세 인식 정확도 개선 실험

## 기술 스택

### Mobile
- Kotlin
- Android Studio

### Backend / Cloud
- Firebase Authentication
- Firebase Realtime Database

### AI / Computer Vision
- TensorFlow Lite MoveNet
- Pose Estimation

## 프로젝트 구조

```text
MainActivity
 ├── 로그인 및 사용자 정보 조회
 ├── 운동 루틴 추천
 ├── 운동 상세 화면 이동
 └── 운동 피드백 기능 연동

PoseFeedbackActivity
 └── MoveNet 기반 자세 피드백
```

## 기술적 도전 과제

운동 자세 판별 과정에서 사람마다 촬영 각도, 거리, 신체 비율 차이로 인해 관절 인식 정확도에 편차가 발생했습니다.

특히 스쿼트 자세 인식 시 관절 좌표 기반 임계값(threshold)을 일반화하는 과정에서 어려움을 겪었으며, 이를 개선하기 위한 피드백 로직 및 자세 분석 방식을 실험했습니다.
